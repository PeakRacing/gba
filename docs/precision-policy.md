# 精度与验收边界

用户在 2026-10-14 明确选择单一快速核心。这里区分功能正确性、允许近似与未覆盖项，不以删除测试、修改预期或把启动当作兼容通过来处理差异。

| 类别 | 契约与证据 |
| --- | --- |
| 指令、内存、持久化 | 保持功能正确性；指令结果、内存内容、丢中断、FIFO 补充、损坏/短读、保存恢复和数据丢失不豁免 |
| 未定义标志 | ARM7TDMI 长乘法 C 未定义；20 个固定失败已逐项验证乘积和 N/Z/V 相同、只差 C |
| HLE 耗时 | 提供服务结果及必要内存/硬件副作用，省略 BIOS 逐指令执行；固定 timing 的 140 个 HLE 耗时差异保留 |
| 总线周期 | 紧凑 WAITCNT/预取/DMA 模型，保留基础访问与仲裁；66 个跨区 LDM/Game Pak/DMA 周期测量差异保留 |
| IRQ/定时器相位 | 固定 timers 测试通过 IRQ handler 停止定时器，并在 HLE IntrWait 校准后比较轮询次数和结束计数。431 个差异记录为该时序模型限制；不是允许计数器算术出错或丢请求 |
| IRQ 读取边界 | timer-IRQ 的 21 个差异涉及读取发生在 handler 前/后；保留原始值，功能回归另覆盖请求、确认、返回、级联和缓存失效 |
| 开放总线和状态轮询 | misc-edge 的 7 个差异测量无效地址 DMA 可见窗口及 HLE Halt 返回后的 DISPSTAT 轮询相位；普通 DMA/内存分项及开放总线锁存回归通过 |
| 图形 | 扫描线近似，保留模式、OBJ、窗口、马赛克与混合。视频 6/7 精确一致；Layer toggle 2 的既定帧差异保留，不增加逐点渲染 |
| 音频 | 保留整数混合、基本频率/长度/包络、FIFO 与定时器触发，不增加昂贵重采样/滤波。PCM 方波频率、长度和包络回归通过；不声称模拟全部模拟电路特性 |
| RTC | 运行期间平台 tick 推进，分钟 IRQ 为 tick 粒度的 30 秒有效期近似；不模拟未知 duty/hold 位或电气波形 |

上述固定失败全部进入精确的允许记录，见 [fast-approximations.json](fast-approximations.json)。`test/fast_acceptance.py` 只匹配已有测试身份、结果值及视频帧 SHA256；新增或变化的差异返回失败。它不会修改严格结果，也不会自动追加记录。`-StrictHardware` 仍失败，`-FastAcceptance` 则执行用户选择的快速精度契约。

未覆盖：完整外部 BIOS、商业 SDK 内部声音服务、联机及传感器之外的长期兼容、实际音频波形品质、MCU 性能/栈高水位和板端掉电。游戏的剧情、保存限制及未到达的关卡另在 SDL 记录中列出。未支持 HLE 服务仍明确返回不支持；不能以空实现替代。

依据是固定测试的原始调用序列与参数、现有功能回归以及 [ARM7TDMI 手册](https://documentation-service.arm.com/static/5f4786a179ff4c392c0ff819) 和 [GBATEK](https://mgba-emu.github.io/gbatek/)。这些分类说明本核心提供的精度，不证明在所有依赖细微时序的游戏中都兼容。
