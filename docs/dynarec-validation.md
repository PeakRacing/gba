# 结构整理与 ARM32 重编译验证（2026-10-15）

代码基于本地未提交的通用优化继续开发；原工作区冻结于忽略目录
`test/out/pre-dynarec-20261015/`，未修改 NES、GBC、gpSP 或掌机固件，未烧录。
当前机器可复核结果见 [结果清单](dynarec-results.json)，其中每个 ARM 测试构建
分别保存 ELF 和源码 SHA256，历史快照没有改写成最终版本的成绩。

## 工程与主机

- 模块头文件独立 C11/C++11 包含、编译器宏与非法配置拒绝共 104 项通过。
- 关闭及开启便携优化均通过六配置断言：971、1102、1116、683、1029、13，
  合计 4914；固定 13 ROM 的常驻/流式与跳帧状态比较通过。
- 严格测试仍保留既有 685 项比较差异；快速精度门禁新增未知差异为零。
  六个已通过视频场景逐像素保持一致；Layer toggle 2 仍为登记的 958 像素行内差异。
- 非跟踪便携路径：128 场景/32768 边界、2658 IRQ 样本，80 取指场景/2500 边界，
  96 绘制场景/1540 变体通过；四款 900 帧的固定旧核心/便携优化/LTO 回放一致。
- SDL2/SDL3 的 MSVC release 生产和测试目标均构建通过。SDL2 八款固定脚本
  回放 3600～18000 帧，120 帧即时恢复重放及五次退出重载均通过。
  此处是有限脚本执行与重放验证，未把八款游戏的完整流程或每项存档都标为兼容通过。
- Cortex-M4 七种配置完成无堆静态链接；RT-Thread 实际头文件的有堆/无堆接口编译通过。
  这些是便携解释器/优化路径的交叉检查，不是 Cortex-M 重编译后端。

## 无探针结构整理基准

使用同一 MinGW GCC、相同本地 ROM SHA256、固定输入与 RTC=0，预热 120 帧，
测量 600 帧。每个配置/游戏先成对交替运行五次；首次退化超过 5% 的组合
增加第二批五次。初次发现《黄金太阳》退化后，恢复访存辅助函数的模块内
可内联实现，再完整重测。早期失败记录保留于忽略目录。

| 配置 | 八款中位耗时总和相对冻结工作区 |
|---|---:|
| RGB565，声音开启 | -0.96% |
| 32 位，声音开启 | -0.14% |
| 半屏流式，声音开启 | -0.63% |
| RGB565，声音关闭 | -0.41% |

32 个组合没有连续两批超过 5% 的退化。该表用于确认结构整理没有实质速度
损失，幅度很小，不将其表述为新的显著性能提升。
`GBA_TEST_MODE=0`、`GBA_TEST_PROFILE=0`、`GBA_DYNAREC=0`；该表不是 ARM 重编译速度。
逐次耗时、ROM 身份和输出保存在结果清单的 `interpreter_production_benchmark`。

## ARM926 实际生成代码验证

QEMU 11.0.50 的 versatilepb/ARM926，ARM GCC 14.3.1、`-O2 -marm`，
自有裸机端口通过 CP15 发布并执行生成的 A32 代码。参考实例用 `gba_step()`，
重编译实例用连续运行接口；比较完整硬件状态、寄存器组、流水线、IO、
硬件 RAM、framebuffer 与输出 PCM。CPU 指令检查不以 TEST_MODE 关闭原生路径。

- 13 个固定参考 ROM 曾逐指令比较约 131 万个检查点，通过。测试中修复了
  ARM7 `Rd=PC` 测试指令的 SPSR 恢复回退，未归为允许近似。
- 最终核心快照的合成/13 ROM 检查包括条件执行、移位边界、乘法、分支、
  内存宽度和非对齐、ROM 预取、DMA、自修改/镜像、定时器 IRQ、缓存回收。
- 两个独立代码/元数据缓存的实例交错运行通过；小缓存触发真实回收。
- 解释器/重编译的 GAST v7 文件摘要相同；恢复重放、32 处 CRC 损坏拒绝、
  短写保留旧文件、替换失败与重试、绑定参数/重叠/发布失败检查通过。
- 流式 ROM 的 13 个参考程序及跨页短读/重新加载通过。
- 八款游戏各 900 帧加 13 个参考 ROM 的块执行差分通过，13717 个综合检查点。
  该构建在增加“统计默认编译移除”开关之前完成；保留其独立源码/ELF 指纹。
  增加统计开关后的当前核心又完成八款各 60 帧，以及参考 ROM 和双实例/存储回归。
- 统计关闭的生产代码路径另外通过参考 ROM 和 CPU/存储检查；
  无 `gba_test_instruction`、`gba_profile_ticks` 或 libc 堆分配符号。

长回放快照累计执行原生运算/分支 174893132 条、访存辅助路径 34943187 条、
解释器回退 18115130 条。访存辅助与回退单独记录，未计作纯原生运算。
当前快照的缓存命中、编译次数和代码占用由 acceptance-final 结果记录。
统计构建使用 `GBA_DYNAREC_STATS=1`，只用于覆盖和缓存诊断，不提供速度结论。

## 资源及未覆盖

便携 Cortex-M4 `-Os` 链接，text/BSS 字节分别为：默认 27252/609260、
最小 19564/439788、完整 32828/687356、半屏流式 33148/604924、
交换/跳帧 27576/642028、小存档 27216/478700、便携完整优化 33376/717440。
data 均为零。各配置最大单函数栈记录在 JSON 中。

ARM926 重编译默认借用 256 KiB 代码和 64 KiB 元数据，替代旧预解码缓存；
与现有画面缓存开关分开计算，不把画面缓存算成重编译固有开销。
`-O2` 下代码查找/翻译函数最大静态栈 256 字节；所链接核心的最大单函数栈
为状态加载 2856 字节，PPU 为 840 字节。测试端口用于两实例、内存文件和
32 MiB ROM 的大缓冲不属于生产核心资源预算。

**ARM32 原生性能未验收。** QEMU 墙钟时间不是 ARM926 板端速度。
未覆盖完整外部 BIOS、新的目标板运行、断电测试，以及 Cortex-M/AArch64/x64
代码生成器；Thumb 宿主编译未验收。保留既有游戏流程和精度限制，
尤其《黄金太阳》实际游戏内存档流程仍未补成完整验收。
